# Contributing

Thanks for your interest in the FalaAI API Go SDK.

## Before you start

- **Bugs and questions:** open an issue.
- **Security issues:** do **not** open a public issue - see [SECURITY.md](SECURITY.md).
- **Features:** open an issue first so we can align on the approach.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep the change focused - one concern per pull request.
3. Make sure the build passes (see the CI badge on the README).
4. Do not commit generated files, logs, or API keys.

## Code of conduct

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
